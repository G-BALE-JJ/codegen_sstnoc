# ADR 0001：项目中枢与源码分离

## 状态

已接受

## 背景

SST codegen 项目需要在 `tilelang` 和 `TileOPs` 之外维护统一的规划、进度和技术决策。若把这些内容混在源码仓库中，容易造成改动边界不清晰，也不利于 agent 按职责执行任务。

## 决策

采用 `codegen_sstnoc` 作为项目中枢目录，用于存放计划、发现、进度、决策和辅助脚本；源码修改继续只在 `tilelang` 中完成。

## 影响

- 项目结构更清晰。
- 规划与实现分离，便于长期维护。
- agent 更容易根据文档执行任务。
- 需要额外维护一个独立的文档目录。
